# HyBand dependencies. Versions are what the model was trained and tested with.

# INSTALL ORDER MATTERS -- torch must be present before the two compiled
# packages, and both need --no-build-isolation so they build against THAT torch
# rather than a fresh one pip would otherwise fetch:
#
#   python -m venv .venv && source .venv/bin/activate
#   pip install -U pip wheel
#   pip install torch --index-url https://download.pytorch.org/whl/cu126
#   pip install -r requirements.txt
#   pip install --no-build-isolation causal-conv1d==1.6.2.post1 mamba-ssm==2.3.2.post1
#
# torch is NOT pinned here: install the build matching your CUDA first.
# This reference environment is python 3.12.3 / torch 2.13.0+cu126.
